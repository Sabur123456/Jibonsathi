# জীবনসাথী Android প্রোটোটাইপ

বাংলা ভাষায় মুসলিম পাত্র-পাত্রীর ম্যাচিং অ্যাপের একটি প্রাথমিক Android Studio প্রকল্প।

## অন্তর্ভুক্ত
- Kotlin + Jetpack Compose UI
- নমুনা প্রোফাইল কার্ড
- নাম/শহর অনুসন্ধান
- পাত্র/পাত্রী ও দেশ ফিল্টার
- পছন্দের তালিকা (অ্যাপ চালু থাকা অবস্থায়)
- প্রোফাইল ফর্মের স্থানীয় প্রিভিউ
- ফ্রি ও প্রিমিয়াম স্ক্রিন (পেমেন্ট কার্যকর নয়)

## APK তৈরি
1. কম্পিউটারে Android Studio (JDK 17 সমর্থিত সংস্করণ) ইনস্টল করুন।
2. ZIP ফাইলটি Extract করুন।
3. Android Studio-তে `JibonSathi` ফোল্ডারটি Open করুন।
4. Gradle sync শেষ হতে দিন এবং প্রয়োজনে SDK Platform 35 ইনস্টল করুন।
5. `Build > Build APK(s)` নির্বাচন করুন।
6. ডিবাগ APK সাধারণত `app/build/outputs/apk/debug/app-debug.apk`-এ তৈরি হবে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি ডেমো প্রোটোটাইপ, উৎপাদন-প্রস্তুত বিয়ের অ্যাপ নয়। কোনো বাস্তব নিবন্ধন, ব্যাকএন্ড, পাসওয়ার্ড/OTP লগইন, ক্লাউড ডেটাবেস, ছবি আপলোড, চ্যাট, যাচাইকরণ, রিপোর্টিং, পেমেন্ট বা অ্যাডমিন প্যানেল যুক্ত নেই। নমুনা প্রোফাইল বাস্তব মানুষ নয়।

## প্রকাশের আগে আবশ্যক
- নিরাপদ অথেনটিকেশন ও ব্যাকএন্ড API
- ডেটাবেসে ব্যক্তিগত তথ্য এনক্রিপশন ও অ্যাক্সেস নিয়ন্ত্রণ
- সম্মতি-ভিত্তিক যোগাযোগ, ব্লক/রিপোর্ট, মডারেশন ও প্রোফাইল যাচাই
- প্রাইভেসি পলিসি, অ্যাকাউন্ট ও তথ্য মুছে ফেলার ব্যবস্থা
- প্রিমিয়াম মূল্য, পেমেন্ট প্রদানকারী এবং স্টোর নীতিমালা যাচাই
- বাস্তব ডিভাইসে পরীক্ষা, অ্যাক্সেসিবিলিটি ও বাংলা ফন্ট পরীক্ষা

## প্রস্তাবিত পরবর্তী আর্কিটেকচার
Android (Kotlin/Compose) + Web (React/Next.js) → HTTPS API → PostgreSQL database + private object storage.
অথেনটিকেশন, rate limiting, server-side validation, audit logs ও moderation যোগ না করে বাস্তব ব্যবহারকারীর সংবেদনশীল তথ্য সংগ্রহ করবেন না।
